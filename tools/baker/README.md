# Baker

`baker` is a lightweight Go AST extraction tool designed as an intermediate step for decomposing large autogenerated Go files (such as ANTLR parsers) into smaller, modular files.

It can either:
- **Output JSON**: Structure declarations, receiver methods, interfaces, and functions grouped under potential new file names, with an `<uncategorized>` section at the very end.
- **Generate Files (`-out <dir>`)**: Directly generate the split `.go` source files in the specified directory, printing each generated filename to `stdout`.

## Usage

### From inside `tools/baker`:

```bash
cd tools/baker

# Print JSON to stdout
go run . <path/to/file.go>

# Print compact JSON to stdout
go run . -compact <path/to/file.go>

# Generate split Go files in a folder and print filenames to stdout
go run . -out ../../pkg/dmlex/split <path/to/file.go>
```

### From repository root:

```bash
# Print JSON to stdout
(cd tools/baker && go run . "$(realpath <path/to/file.go>)")

# Generate split Go files
(cd tools/baker && go run . -out "$(realpath ./pkg/dmlex/split)" "$(realpath <path/to/file.go>)")
```

## Exit Codes

| Exit Code | Meaning |
|---|---|
| `0` | Success. All symbols were categorized; zero uncategorized leftovers. |
| `1` | Completed (JSON printed or files generated), but `<uncategorized>` contains leftover symbols. |
| `2` | Error occurred (invalid usage, missing arguments, I/O error, or AST parsing failure). |

## JSON Schema

```json
{
  "<input_basename>_<snake_case_name>.go": {
    "structures": [
      {
        "name": "DmlContext",
        "code": "type DmlContext struct {\n\tantlr.BaseParserRuleContext\n\tparser antlr.Parser\n}",
        "methods": [
          {
            "name": "GetParser",
            "receiver": "(s *DmlContext)",
            "code": "func (s *DmlContext) GetParser() antlr.Parser { return s.parser }"
          }
        ]
      }
    ],
    "interfaces": [
      {
        "name": "IDmlContext",
        "code": "// IDmlContext is an interface to support dynamic dispatch.\ntype IDmlContext interface {\n\t...\n}"
      }
    ],
    "functions": [
      {
        "name": "NewDmlContext",
        "code": "func NewDmlContext(...) *DmlContext {\n\t...\n}"
      }
    ]
  },
  "<uncategorized>": {
    "structures": [],
    "interfaces": [],
    "functions": [
      {
        "name": "dmlParserInit",
        "code": "func dmlParserInit() {\n\t...\n}"
      }
    ]
  }
}
```
